# GENIO

**Status:** In Development  
**Portfolio:** https://trifarafael.com/projects/genio-ai-orchestrator  
**Creator / Developer:** [Trifa Rafael](https://trifarafael.com)

GENIO is a **multi-model AI orchestrator** designed to act as a central brain/router across multiple AI models and specialized agents.

Instead of forcing the user to decide which model should handle every part of a complex task, GENIO is being built to interpret the objective, break it into steps, route each step to the right model or agent, coordinate execution and review the result before delivery.

## Core idea

GENIO is not intended to be just another chat interface.

The system is being designed around:

- intelligent routing between multiple AI models
- specialized agents for different types of work
- decomposition of complex objectives into actionable tasks
- parallel execution where useful
- shared project context
- modular provider/model adapters
- critic / review stages
- final-output validation
- project files and workspace context
- executor / autobuilder workflows for more autonomous multi-step work

## Why GENIO

Different AI models are good at different things. GENIO's purpose is to make those differences useful automatically, so the user can focus on the result rather than manually switching between models, prompts and tools.

## Current stage

GENIO is in **active development**. Architecture, routing, execution and review systems are still evolving.
